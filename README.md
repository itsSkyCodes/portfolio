### 1. MyRelma — Multi-Tenant Career-Coaching SaaS Platform
> **Stack:** NestJS · TypeScript · PostgreSQL · TypeORM · Redis · BullMQ · OpenAI GPT-4o · CrewAI · Pinecone · Pusher · Cloudflare R2 · Google APIs · LinkedIn API  
> **Timeline:** Jun 2025 – Present | **Role:** Tech Lead & Full-Stack Architect

- **Zero-to-Production SaaS Architecture:** Architected and engineered the platform from scratch with a **27-module NestJS REST API**, PostgreSQL/TypeORM multi-tenant data isolation, and Redis/BullMQ background processing across **10 job queues**, maintaining **99%+ uptime** across **20+ tenant organizations** while leading a 3-person engineering team.
- **Generative AI Career Assistant:** Engineered a production GenAI assistant (**FastAPI + CrewAI + OpenAI GPT-4o + Pinecone RAG**) with 6 production endpoints:
  - Multi-format document parser (PDF, DOCX, JPEG, PNG).
  - Section-by-section ATS-aligned rewriting with structured Pydantic outputs.
  - Full resume audit with rubric scoring and automated feedback.
  - Real-time **Server-Sent Events (SSE) conversational resume chat** driven by an LLM classifier routing across 9 message types (**62K+ lines of service logic**), token-usage tracking, and per-user rate limiting.
- **Context-Aware Email Assistant:** Built an OpenAI-powered composition assistant streaming real-time drafts via SSE with thread-aware prompt engineering, integrated alongside two-way Google Workspace sync (Gmail, Contacts, Calendar, Tasks) and LinkedIn OAuth 2.0.
- **Enterprise Security & Reliability:** Implemented Redis-backed distributed rate limiting with automated PostgreSQL failover, per-email authentication throttling to mitigate OTP brute-force attacks, Helmet HTTP hardening, strict TLS/CORS rules, and graceful shutdown lifecycle hooks.

### Web Application Stack
- **Framework:** Next.js 16 (App Router) with React 19
- **Language:** TypeScript

### Requirements
- Node.js 20.9 or newer (see `.nvmrc`)
- npm

```bash
nvm use
```

### Local Setup
```bash
# 1. Install dependencies
npm install

# 2. Configure environment variables
cp .env.example .env.local

# 3. Start development server
npm run dev
```

### Environment Variables (`.env.local`)
| Variable | Purpose |
| :--- | :--- |
| `NEXT_PUBLIC_SITE_URL` | Canonical URL, Open Graph, sitemap, and robots. Absolute, no trailing slash. |
| `BREVO_API_KEY` | Brevo API key (server-only). |
| `BREVO_SENDER_EMAIL` | Verified Brevo sender address. |
| `BREVO_SENDER_NAME` | Name displayed on outgoing emails. |
| `BREVO_RECIPIENT_EMAIL` | Inbox receiving portfolio contact submissions. |

### Available Scripts
```bash
npm run dev     # Start development server with Turbopack
npm run build   # Build optimized production bundle
npm run start   # Run production server
npm run lint    # Run ESLint validation
```

### Deployment (Vercel)
1. Push repository to GitHub.
2. Import repository on [Vercel](https://vercel.com).
3. Set Node.js version to **22.x** in project settings.
4. Add all environment variables from `.env.example`.
5. Deploy.
